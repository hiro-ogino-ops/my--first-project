# フラッシュタイマー

開始時刻（既定 8:30）から **作業50分 → 休憩10分** を繰り返し、切り替わるたびに画面全体を光らせる単体アプリです。

```
8:30 開始 ─50分─▶ 9:20 ⚡ ─10分─▶ 9:30 ⚡ ─50分─▶ 10:20 ⚡ ─10分─▶ 10:30 ⚡ …
```

## 使い方

`apps/flash-timer/index.html` をブラウザで開くだけです。ビルドも依存もありません。

- **開始時刻 / 作業（分）/ 休憩（分）** … 自由に変更できます。設定はブラウザに保存されます。
- **今すぐ開始** … 開始時刻を現在時刻に合わせ、そこから 50/10 を回します。
- **テスト点灯** … フラッシュの見え方と音を確認します。
- **全画面** … 見やすい全画面表示に切り替えます。
- **音も鳴らす** … フラッシュと同時に短いビープを2回鳴らします（初回はページを一度クリックしてください）。
- **開始時にも光らせる** … 開始時刻ちょうどにも光らせます。
- **画面を消さない** … 対応ブラウザで画面のスリープを抑止します。

## 作りのメモ

- 経過時間を足し込むのではなく**壁時計から現在のセットを毎回計算**するため、タブを裏にしていても切り替え時刻がずれません。
- スリープや裏タブで境界を飛ばした場合も、経過フラッシュ回数の差分で検出して復帰時に1回光ります。
- 点滅は約2Hz（光感受性発作の目安とされる3Hz未満）に抑え、`prefers-reduced-motion` 指定時は点滅せず1回だけ淡くフェードします。
- 日付が変わると、その日の開始時刻まで「開始待ち」に戻ります。
